Low-stock inventory alerts widget (PRD §3.2) intentionally omitted — depends on the Inventory module, which is Phase 2 per the product brief.

Roles with access

  • Owner/Admin, Manager — full view, all widgets, all drill-down links active.
  • Cashier — view only; same widgets, but no settings/edit affordances anywhere on this screen (there are none on Dashboard regardless — informational only).
  • Server/Waiter, Chef/Kitchen Staff — no access; nav item not shown for these roles (grayed here only to document the full matrix).

Data loaded on entry

  • GET /dashboard/summary?date=today — gross/net/tax/discount KPIs, payment mode breakdown (cached 60s TTL per PRD §3.2).
  • GET /tables?status=occupied&count=true, GET /kots?status=in-kitchen,ready&count=true — Live Ops tiles, pushed in real time over Socket.io.
  • GET /reports/top-dishes?range=today&limit=5.

Every button's action + destination

  • KPI cards — informational, not clickable.
  • "Tables Occupied" tile — navigates to Table & Area Grid.
  • "Orders in Kitchen" / "Ready to Serve" tiles — navigate to Kitchen Display (KDS).
  • "View full report" — navigates to Reports, Top Dishes tab, pre-filtered to today.

Empty state

  • No orders yet today: KPI cards show "₹0" and "No sales recorded yet today."; Top Dishes card shows "No dishes sold yet today."

Error state

  • Dashboard summary API fails/cache miss on a cold start: banner "Couldn't load dashboard data. Retry." with a "Retry" button in place of the KPI row.
