Roles with access

  • Owner/Admin, Manager, Cashier — full access to this screen.
  • Server/Waiter — no access (no billing per RBAC matrix); nav has no path here for Server.
  • Chef/Kitchen Staff — no access.
  • Discount above the configured threshold — Cashier sees the lock note and a disabled "Apply", plus a "Request Manager Approval" action that opens a manager PIN/approval modal (not pictured, annotated only). Manager/Owner can apply over-threshold discounts directly, or approve a Cashier's pending request.

Data loaded on entry

  • GET /orders/:id — must be in Served status (or later) to reach this screen; itemized lines, notes.
  • GET /settings/tax-config — CGST/SGST rates/slabs for the tax breakdown.
  • GET /settings/discount-policy — auto-approve threshold used for the lock logic.

Every button's action + destination

  • %/Flat ₹ toggle — switches discount input mode, no navigation.
  • "Apply" (discount) — validates against threshold: under threshold, updates totals immediately; over threshold, shows the lock note and requires manager approval before it applies.
  • Payment method tabs — switch Cash/Card/UPI/Split panel. Split reveals per-method amount rows with a running "Remaining: ₹—" check; "Settle Bill" stays disabled until remaining is ₹0.
  • "Settle Bill" — POST /orders/:id/settle → generates the sequential invoice (PDF), order status Billed → Closed, table auto-freed to Needs Cleaning; screen swaps in-page to the confirmation state shown above.
  • "Print Invoice" — sends to the connected thermal/ESC-POS printer over the LAN bridge; no navigation, shows a toast on success/failure.
  • "Download PDF" (confirmation state) — downloads the invoice PDF.
  • "Void/Refund" — Owner/Manager only; opens a confirm + mandatory reason modal, fully audit-logged (PRD §3.10), restricted after settlement.
  • "Done" (confirmation state) — returns to Table & Area Grid.

Empty state

  • Not applicable — an order can't reach Settle Bill with zero items (Send to Kitchen is disabled on an empty cart back in New Order).

Error state

  • Settlement fails (network/printer issue): "Bill not settled — check your connection and try again." Order stays in Served status, nothing is double-charged.
  • Split payment amounts don't add up to total: "Split amounts don't add up to the total. Adjust and try again."
