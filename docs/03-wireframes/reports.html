Other tabs (Revenue by Category, Revenue by Payment Mode, Top Dishes, Staff Performance) reuse this same shell — filter bar + tabs stay fixed, only the chart-placeholder + table below swap. Not redrawn individually here to avoid duplicating the same layout four more times; each tab's specific columns are described in the annotation block below.

Roles with access

  • Owner/Admin, Manager — full: all 5 tabs, custom range, all export formats.
  • Cashier — sales-only: Sales Overview, Revenue by Category, Revenue by Payment Mode, Top Dishes. Staff Performance tab is hidden (personnel data) — this is the interpretation of "sales only," flagged as a judgment call on the sitemap.
  • Server/Waiter, Chef/Kitchen Staff — no access; nav item hidden entirely.

Data loaded on entry

  • GET /reports/sales?range=&groupBy=hour — Sales Overview.
  • GET /reports/category?range= — Revenue by Category: horizontal bar-list + table (Category, Revenue, % of total, Orders).
  • GET /reports/payment-mode?range= — Revenue by Payment Mode: pie-placeholder + table (Cash/Card/UPI/Split, amount, %).
  • GET /reports/top-dishes?range= — ranked table (Rank, Dish, Qty Sold, Revenue) + a "Slow Moving Items" sub-table.
  • GET /reports/staff-performance?range= — table (Staff, Orders Handled, Avg Table Turnaround, Discounts Applied). Owner/Manager only.

Every button's action + destination

  • Date preset click — reloads all report data for that range, no navigation.
  • "Apply" (custom range) — same, using the From/To fields.
  • Tab click — swaps the chart + table below, keeping the current date range.
  • Export buttons — trigger a file download of the currently active tab's data; toast "Report exported."

Empty state

  • No sales in the selected range: "No sales in this date range. Try a different range." in place of the chart and table.

Error state

  • Export fails: "Export failed — try again in a moment."
