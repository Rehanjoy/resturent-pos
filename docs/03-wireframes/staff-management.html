Roles with access

  • Owner/Admin — full: add, edit, deactivate/reactivate, reassign roles, view activity log, revoke sessions.
  • Manager — view + add only: can see the list and add new staff, cannot edit existing staff details/role or deactivate them (per RBAC "View/Add").
  • Cashier, Server/Waiter, Chef/Kitchen Staff — no access; nav item hidden entirely.

Data loaded on entry

  • GET /staff?restaurantId= with filters/pagination.
  • GET /auditLogs?staffId= — loaded on "Activity" click.
  • GET /sessions?staffId= — active-sessions panel.

Every button's action + destination

  • "+ Add Staff" — opens the Add/Edit Staff form (shown inline here; modal/side-panel in the real build).
  • Row "Edit" — opens the same form, pre-filled (Owner/Admin only — Manager doesn't see this link on existing rows).
  • Row "Deactivate"/"Reactivate" — confirm modal: "Deactivate Asha Devi? They won't be able to log in until reactivated." Owner/Admin only.
  • Row "Activity" — jumps to the Activity Log section for that staff member.
  • "Revoke" (session) — immediately ends that session/logs the device out, confirm before action.
  • "Regenerate PIN" — issues a new 4-digit PIN, old one invalidated immediately.
  • Form "Save" — POST/PUT /staff/:id, returns to list with the new/updated row visible.

Empty state

  • No other staff besides the logged-in Owner: "No other staff added yet. Add your first team member." with an "Add Staff" button.

Error state

  • Duplicate email: "That email is already in use by another staff account."
  • PIN collision: "That PIN is already in use — try another."
